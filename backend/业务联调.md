# 预约、诊疗与结算联调

以下步骤对应协作约定 v1.5 第 9.6 至 9.9 节。手动示例会在连接的演示库中创建患者、预约、就诊、结算单和操作记录。记录会保留，可在网页上按本次生成的患者账号查询。

## 启动演示后端

准备 Java 17、MySQL 8，并确认 backend/application-local.properties 已指向本机演示库。打开第一个 PowerShell 窗口运行以下命令。

```powershell
Set-Location 'E:\adc-system\backend'
$env:SPRING_PROFILES_ACTIVE = 'demo'
.\mvnw.cmd spring-boot:run
```

V7 写入 2026 年 7 至 11 月的 26 条历史预约及对应业务记录。每次以 demo 配置启动时，后端按北京时间检查当天的预约。当天为空时才建立六条演示预约，当天已有预约时保留已有记录。尚未取消或到诊的预约在预约时间过去后显示为“待核实”。V8 为结算单保存患者账号、患者姓名、诊所名称和牙医姓名，供重打原单使用，并按开单日期接续已有流水号。

## 准备请求和演示患者

以下 HTTP 示例在同一个 PowerShell 窗口依次执行，支持 Windows PowerShell 5.1 和 PowerShell 7。每个调用显示路径和实际状态码。写操作自动生成 X-Request-Id，显式传入同一标识可模拟网络重试。日期和时刻统一以北京时间计算。默认服务地址为 http://localhost:8080。

```powershell
Add-Type -AssemblyName System.Net.Http
$adcBase = 'http://localhost:8080/api'
$bizHttp = [System.Net.Http.HttpClient]::new()
function Invoke-AdcBusiness {
    param([string]$Method, [string]$Path, [string]$Token, $Body = $null,
          [int]$Expect = 200, [string]$RequestId)
    $request = [System.Net.Http.HttpRequestMessage]::new(
        [System.Net.Http.HttpMethod]::new($Method), "$adcBase$Path")
    try {
        if ($Token) { $request.Headers.Add('Authorization', "Bearer $Token") }
        if ($Method -eq 'POST' -and $Path -notmatch '/(login|check|price-lines|settlement-preview)$') {
            if (!$RequestId) { $RequestId = [guid]::NewGuid().ToString() }
            $request.Headers.Add('X-Request-Id', $RequestId)
        }
        if ($null -ne $Body) {
            $payload = ConvertTo-Json -InputObject $Body -Depth 12 -Compress
            $request.Content = [System.Net.Http.StringContent]::new(
                $payload, [Text.Encoding]::UTF8, 'application/json')
        }
        $response = $bizHttp.SendAsync($request).GetAwaiter().GetResult()
        try {
            $code = [int]$response.StatusCode
            $raw = $response.Content.ReadAsStringAsync().GetAwaiter().GetResult()
            Write-Host "$Method $Path -> $code"
            if ($code -ne $Expect) { throw "预期 $Expect，实际 $code，响应 $raw" }
            if ($raw) { ConvertFrom-Json -InputObject $raw }
        } finally { $response.Dispose() }
    } finally { $request.Dispose() }
}
function Get-AdcBusinessToken([string]$Name) {
    (Invoke-AdcBusiness POST '/auth/login' -Body @{ username=$Name; password='123456' }).token
}
function Get-AdcBeijingNow {
    [DateTimeOffset]::UtcNow.ToOffset([TimeSpan]::FromHours(8))
}
$front = Get-AdcBusinessToken 'front1'
$doctor = Get-AdcBusinessToken 'dentist1'
$otherDoctor = Get-AdcBusinessToken 'dentist2'
$hq = Get-AdcBusinessToken 'hq1'
$tag = [guid]::NewGuid().ToString('N').Substring(0,8)
$patient = Invoke-AdcBusiness POST '/patients' $front @{
    name="业务联调-$tag"; birthDate='1990-05-01'; billingAddress='演示地址一号'
    phone='13900008888'; email=$null; emergencyName='黄敏'; emergencyPhone='13900008889'; allergyIds=@()
} -Expect 201
$patient | Select-Object id,accountNo,name
$d1 = Invoke-AdcBusiness GET '/auth/me' $doctor
$clinic = @(Invoke-AdcBusiness GET '/options/clinics' $front)[0]
$items = @(Invoke-AdcBusiness GET '/options/treatment-items' $front)
$item = $items | Where-Object { $_.quantityScale -eq 0 -and $null -ne $_.currentPrice } | Select-Object -First 1
if (!$clinic -or !$item -or !$d1.dentistId) { throw '需要一间启用诊所、一项已定价的整数治疗项目及绑定牙医的演示账号' }
$fmt = "yyyy-MM-dd'T'HH:mm:ss"
$slot = (Get-AdcBeijingNow).AddDays(2).AddSeconds((Get-Random -Minimum 0 -Maximum 864000))
$booking = @{patientId=$patient.id; dentistId=$d1.dentistId; clinicId=$clinic.id
             scheduledAt=$slot.ToString($fmt); itemIds=@($item.id)}
```

## 预约、取消和登记到诊

先检查并创建一个预约，重放同一次请求。换新标识再次预约应报告患者或牙医的时间冲突。用旧版本尝试取消会得到带最新预约的 CHANGED。取消后可以重新使用同一时段。

```powershell
$invalid = $booking.Clone()
$invalid.scheduledAt = (Get-AdcBeijingNow).AddHours(-1).ToString($fmt)
$invalid.itemIds = @()
Invoke-AdcBusiness POST '/appointments/check' $front $invalid | ConvertTo-Json -Depth 5
(Invoke-AdcBusiness POST '/appointments' $front $invalid -Expect 400).fieldErrors
Invoke-AdcBusiness POST '/appointments/check' $front $booking
$rid = [guid]::NewGuid().ToString()
$first = Invoke-AdcBusiness POST '/appointments' $front $booking -Expect 201 -RequestId $rid
$retry = Invoke-AdcBusiness POST '/appointments' $front $booking -Expect 201 -RequestId $rid
if ($retry.id -ne $first.id) { throw '同一请求标识返回了不同预约' }
(Invoke-AdcBusiness POST '/appointments' $front $booking -Expect 409).message
$path = "/appointments/$($first.id)"
Invoke-AdcBusiness GET $path $doctor
(Invoke-AdcBusiness GET $path $otherDoctor -Expect 403).code
$day = $slot.ToString('yyyy-MM-dd')
Invoke-AdcBusiness GET "/appointments?from=$day&to=$day&clinicId=$($clinic.id)&dentistId=$($d1.dentistId)&patientId=$($patient.id)&status=VALID,CANCELLED" $hq
$stale = Invoke-AdcBusiness POST "$path/cancel" $front @{version=99} -Expect 409
$stale | Select-Object code,current
$cancelled = Invoke-AdcBusiness POST "$path/cancel" $front @{version=$first.version}
$cancelled | Select-Object status,cancelledAt,cancelledBy,version
Invoke-AdcBusiness POST "$path/cancel" $front @{version=$first.version}
(Invoke-AdcBusiness POST "$path/arrive" $front @{version=$cancelled.version} -Expect 409).code
```

为同一时段重新创建预约并登记到诊。实际到诊时间取当前北京时间，未指定接诊牙医和诊所时沿用预约值。重复到诊应返回同一 visitId，已到诊的预约不能取消。

```powershell
$booked = Invoke-AdcBusiness POST '/appointments' $front $booking -Expect 201
$path = "/appointments/$($booked.id)"
$arrive = @{arrivedAt=$slot.ToString($fmt); dentistId=$null; clinicId=$null; version=$booked.version}
(Invoke-AdcBusiness POST "$path/arrive" $front $arrive -Expect 400).fieldErrors
$arrive.arrivedAt = (Get-AdcBeijingNow).ToString($fmt)
$arrival = Invoke-AdcBusiness POST "$path/arrive" $front $arrive
$again = Invoke-AdcBusiness POST "$path/arrive" $front $arrive
if ($again.visitId -ne $arrival.visitId) { throw '重复到诊返回了不同就诊' }
(Invoke-AdcBusiness POST "$path/cancel" $front @{version=$arrival.appointment.version} -Expect 409).code
$visit = "/visits/$($arrival.visitId)"
$record = "/patients/$($patient.id)/medical-record"
Invoke-AdcBusiness GET $record $doctor
(Invoke-AdcBusiness GET $record $front -Expect 403).code
```

## 诊疗计价、确认和更正

前台可查看就诊，确认须由接诊牙医办理。对已获授权的计价请求，数量精度错误会返回 HTTP 200 和 problems；相同内容提交确认时返回 HTTP 400 和字段路径。未确认就诊不能结算。

```powershell
$v = Invoke-AdcBusiness GET $visit $front
$v | Select-Object id,status,version
$visitDay = $arrive.arrivedAt.Substring(0,10)
Invoke-AdcBusiness GET "/visits?from=$visitDay&to=$visitDay&dentistId=$($d1.dentistId)&status=UNCONFIRMED,CONFIRMED" $hq
(Invoke-AdcBusiness GET $visit $otherDoctor -Expect 403).code
(Invoke-AdcBusiness POST "$visit/settlement-preview" $front -Expect 409).code
$badLines = @(@{itemId=$item.id; quantity=0.5})
$goodLines = @(@{itemId=$item.id; quantity=1})
Invoke-AdcBusiness POST "$visit/price-lines" $doctor @{treatments=$badLines} | ConvertTo-Json -Depth 6
Invoke-AdcBusiness POST "$visit/price-lines" $doctor @{treatments=$goodLines} | ConvertTo-Json -Depth 6
$form = @{problem='牙龈出血'; specialNeeds='无'; relatedHistory=$null; allergyIds=@()
          treatments=$badLines; version=$v.version}
(Invoke-AdcBusiness POST "$visit/confirm" $doctor $form -Expect 400).fieldErrors
$form.treatments = $goodLines
(Invoke-AdcBusiness POST "$visit/confirm" $front $form -Expect 403).code
(Invoke-AdcBusiness POST "$visit/confirm" $otherDoctor $form -Expect 403).code
$confirmed = Invoke-AdcBusiness POST "$visit/confirm" $doctor $form
$confirmed | Select-Object status,version,total
(Invoke-AdcBusiness POST "$visit/confirm" $doctor $form -Expect 409) | Select-Object code,current
Invoke-AdcBusiness GET $record $doctor | ConvertTo-Json -Depth 8
```

## 结算预览、开具和重打

先预览，再由牙医更正治疗数量。旧预览凭据应返回 CHANGED，current 为 null。前台重新预览后开单得到 201，再次办理同一就诊得到 200 和原单。重放完全相同的请求标识则返回第一次的 201。

```powershell
Invoke-AdcBusiness GET "/visits?from=$visitDay&to=$visitDay&status=CONFIRMED" $front
$preview = Invoke-AdcBusiness POST "$visit/settlement-preview" $front
$preview | Select-Object existing,total,checkToken
(Invoke-AdcBusiness POST "$visit/settlement" $front @{} -Expect 400).fieldErrors
$form.version = $confirmed.version
$form.treatments = @(@{itemId=$item.id; quantity=2})
$revised = Invoke-AdcBusiness POST "$visit/confirm" $doctor $form
(Invoke-AdcBusiness POST "$visit/settlement" $front @{checkToken=$preview.checkToken} -Expect 409) | Select-Object code,current
$preview = Invoke-AdcBusiness POST "$visit/settlement-preview" $front
$issue = @{checkToken=$preview.checkToken}
$issueId = [guid]::NewGuid().ToString()
$slip = Invoke-AdcBusiness POST "$visit/settlement" $front $issue -Expect 201 -RequestId $issueId
$replay = Invoke-AdcBusiness POST "$visit/settlement" $front $issue -Expect 201 -RequestId $issueId
$original = Invoke-AdcBusiness POST "$visit/settlement" $front $issue
if ($slip.settlementNo -ne $replay.settlementNo -or $slip.settlementNo -ne $original.settlementNo) {
    throw '重打原单或请求重放返回了不同单号'
}
Invoke-AdcBusiness POST "$visit/settlement-preview" $front | ConvertTo-Json -Depth 8
$issueDate = $slip.settlementNo.Substring(2,8)
$billDay = [datetime]::ParseExact($issueDate,'yyyyMMdd',[cultureinfo]::InvariantCulture).ToString('yyyy-MM-dd')
Invoke-AdcBusiness GET "/settlements?from=$billDay&to=$billDay&keyword=$($patient.accountNo)" $front
Invoke-AdcBusiness GET "/settlements/$($slip.settlementNo)" $front | ConvertTo-Json -Depth 8
(Invoke-AdcBusiness GET "/settlements/$($slip.settlementNo)" $doctor -Expect 403).code
$form.version = $revised.version
(Invoke-AdcBusiness POST "$visit/confirm" $doctor $form -Expect 409).code
```

## 未实施治疗结束

为同一患者另建一次就诊。填写原因后，详情状态为 NO_TREATMENT，诊疗资料会列出结束原因。此前的结算单仍可按单号查询。

```powershell
$booking.scheduledAt = $slot.AddMinutes(15).ToString($fmt)
$later = Invoke-AdcBusiness POST '/appointments' $front $booking -Expect 201
$arrive.version = $later.version
$arrive.arrivedAt = (Get-AdcBeijingNow).ToString($fmt)
$second = Invoke-AdcBusiness POST "/appointments/$($later.id)/arrive" $front $arrive
$otherVisit = "/visits/$($second.visitId)"
$beforeEnd = Invoke-AdcBusiness GET $otherVisit $doctor
$end = @{reason=''; problem='患者身体不适'; version=$beforeEnd.version}
(Invoke-AdcBusiness POST "$otherVisit/end-without-treatment" $doctor $end -Expect 400).fieldErrors
$end.reason = '患者身体不适，改期治疗'
$ended = Invoke-AdcBusiness POST "$otherVisit/end-without-treatment" $doctor $end
$ended | Select-Object status,noTreatmentReason
$form.version = $ended.version
(Invoke-AdcBusiness POST "$otherVisit/confirm" $doctor $form -Expect 409).code
(Invoke-AdcBusiness POST "$otherVisit/settlement-preview" $front -Expect 409).code
Invoke-AdcBusiness GET $record $doctor | ConvertTo-Json -Depth 8
$bizHttp.Dispose()
```

## 已确认的联调口径

1. `price-lines` 对能够解析的计价请求返回 200。数量不合法、没有适用价格、项目重复等问题逐项写入 `problems`，可计价的行保留在 `lines`。同类问题在 `confirm` 中返回 400。
2. 结算单保留开具时显示的患者账号、患者姓名、诊所名称和牙医姓名。重印时保留这些显示值和已确认的治疗价格。
3. 以 demo 启动时，已有任意一条当天预约就跳过补种。空预约日补齐六条，其中 09:00 已到诊未确认、09:30 已确认待结算。其余四条到点后按约定显示为待核实。
4. 确认诊疗时同步校验金额是否能存入现有结算字段。超出数据库可保存的金额时，计价预览提示原因，确认返回 `treatments` 字段错误。
