# 基础资料接口联调

适用范围为《前后端协作约定》第 9.1 至 9.5 节。以下步骤使用 Windows PowerShell 5.1 或 PowerShell 7。手动示例会在当前连接的演示库中新建带随机后缀的记录，并保留这些记录供网页核对。

## 一、启动演示后端

需要 Java 17、MySQL 8 及可用的 Maven Wrapper。沿用 backend/application-local.properties 中已有的本机连接。在第一个 PowerShell 窗口运行以下命令，看到应用启动成功后保持窗口打开。

```powershell
Set-Location 'E:\adc-system\backend'
$env:SPRING_PROFILES_ACTIVE = 'demo'
.\mvnw.cmd spring-boot:run
```

Flyway 会接续已有的 V1 至 V3，执行 V4 公共表调整和 V5 基础演示数据。默认 HTTP 地址为 http://localhost:8080。

## 二、运行独立测试库上的自动化测试

测试配置固定使用库名 adc_auth_test。先在测试用 MySQL 实例中用管理员账号执行以下 SQL，并给测试账号授予该库的建表、迁移和读写权限。

```sql
CREATE DATABASE IF NOT EXISTS adc_auth_test CHARACTER SET utf8mb4;
```

在另一个 PowerShell 窗口执行以下命令。按提示输入刚才授权的 MySQL 测试账号和密码。测试会通过随机 HTTP 端口启动后端并写入该测试库。演示库和测试库可位于同一个实例。

```powershell
Set-Location 'E:\adc-system\backend'
$env:ADC_TEST_DB_HOST = 'localhost'
$env:ADC_TEST_DB_PORT = '3306'
$testLogin = Get-Credential -Message '输入 adc_auth_test 的 MySQL 测试账号'
$env:ADC_TEST_DB_USER = $testLogin.UserName
$env:ADC_TEST_DB_PASSWORD = $testLogin.GetNetworkCredential().Password
try {
    .\mvnw.cmd test
    if ($LASTEXITCODE -ne 0) { throw "Maven 测试失败，退出码 $LASTEXITCODE" }
} finally {
    Remove-Item Env:ADC_TEST_DB_PASSWORD -ErrorAction SilentlyContinue
}
```

Maven 会在 backend/target/surefire-reports 下生成分测试类报告。手动联调使用下面的 HTTP 命令，与这个测试进程独立。

## 三、准备 PowerShell 请求函数和账号

在第二个窗口按文档顺序执行以下代码块。Invoke-Adc 打印状态码并返回解析后的 JSON。预期错误也可直接读取其 code、fieldErrors 和 current。每次写入自动分配请求标识，也可以显式传入相同标识模拟重试。

```powershell
Add-Type -AssemblyName System.Net.Http
$adcHttp = [System.Net.Http.HttpClient]::new()
$adcBase = 'http://localhost:8080/api'
$tag = [guid]::NewGuid().ToString('N').Substring(0,8)

function Invoke-Adc {
    param([string]$Method, [string]$Path, [string]$Token,
          $Body = $null, [string]$RequestId, [int]$Expect = 200)
    $req = [System.Net.Http.HttpRequestMessage]::new(
        [System.Net.Http.HttpMethod]::new($Method), "$adcBase$Path")
    try {
        if ($Token) { $req.Headers.Add('Authorization', "Bearer $Token") }
        if ($Method -in 'POST','PUT' -and $Path -notlike '/auth/*') {
            if (!$RequestId) { $RequestId = [guid]::NewGuid().ToString() }
            $req.Headers.Add('X-Request-Id', $RequestId)
        }
        if ($null -ne $Body) {
            $payload = ConvertTo-Json -InputObject $Body -Depth 12 -Compress
            $req.Content = [System.Net.Http.StringContent]::new(
                $payload, [Text.Encoding]::UTF8, 'application/json')
        }
        $resp = $adcHttp.SendAsync($req).GetAwaiter().GetResult()
        try {
            $status = [int]$resp.StatusCode
            $raw = $resp.Content.ReadAsStringAsync().GetAwaiter().GetResult()
            Write-Host "$Method $Path -> $status"
            if ($status -ne $Expect) { throw "期望 $Expect，收到 $status，响应为 $raw" }
            if ($raw) { ConvertFrom-Json -InputObject $raw }
        } finally { $resp.Dispose() }
    } finally { $req.Dispose() }
}

function Get-AdcToken([string]$Username) {
    (Invoke-Adc POST '/auth/login' -Body @{
        username = $Username
        password = '123456'
    }).token
}
$hq = Get-AdcToken 'hq1'
$front = Get-AdcToken 'front1'
$doctor = Get-AdcToken 'dentist1'
```

## 四、下拉选项

三种岗位都可以调用这五个 GET 接口。activeOnly 默认为 true，改为 false 可以看到停用记录。牙医选项包括已核实资质，治疗项目选项包括今天适用的 currentPrice。

```powershell
Invoke-Adc GET '/options/clinics?activeOnly=true' $front
Invoke-Adc GET '/options/dentists?activeOnly=false' $doctor
Invoke-Adc GET '/options/treatment-items' $hq
$allergies = @(Invoke-Adc GET '/options/allergies' $front)
$allergies
Invoke-Adc GET '/options/qualifications' $front
```

## 五、诊所、请求重放及编辑冲突

下面用同一个标识新建两次，再尝试用同一标识更改内容。前两次应返回同一诊所 ID 和版本，第三次返回 DUPLICATE_REQUEST。换新标识提交重名诊所会得到 CONFLICT。

```powershell
$clinicBody = [ordered]@{
    name = "联调诊所-$tag"; postalAddress = '广州天河路21号'; managerName = '李华'
    phone = '020-12345678'; email = 'office@adc.example'; officeArea = 120.50
}
$rid = [guid]::NewGuid().ToString()
$clinic = Invoke-Adc POST '/clinics' $hq $clinicBody -RequestId $rid -Expect 201
$again = Invoke-Adc POST '/clinics' $hq $clinicBody -RequestId $rid -Expect 201
if ($clinic.id -ne $again.id -or $clinic.version -ne $again.version) { throw '重放结果不同' }
$clinicBody.officeArea = 131.20
(Invoke-Adc POST '/clinics' $hq $clinicBody -RequestId $rid -Expect 409).code
(Invoke-Adc POST '/clinics' $hq $clinicBody -Expect 409).code

$clinicPath = "/clinics/$($clinic.id)"
Invoke-Adc GET '/clinics' $hq
Invoke-Adc GET $clinicPath $hq
$clinicBody.active = $false
$clinicBody.version = $clinic.version
$saved = Invoke-Adc PUT $clinicPath $hq $clinicBody
$saved
$stale = Invoke-Adc PUT $clinicPath $hq $clinicBody -Expect 409
$stale | ConvertTo-Json -Depth 6
(Invoke-Adc GET $clinicPath $front -Expect 403).code
```

更新后的 active 为 false。用旧版再次更新，应看到 CHANGED 和含最新版本的完整 current。前台读取诊所维护接口应得到 FORBIDDEN。

## 六、牙医及资质

先建立资质种类，再把这项资质登记为待核实。PUT 请求携带完整持有列表，核实后再读取牙医详情，可看到资质名称和精确到秒的核实时间。

```powershell
$qBody = @{name = "联调资质-$tag"}
$qual = Invoke-Adc POST '/qualifications' $hq $qBody -Expect 201
(Invoke-Adc POST '/qualifications' $hq $qBody -Expect 409).code
$dBody = @{
    employeeNo = "T$tag"; name = "联调牙医-$tag"; birthDate = '1985-03-12'
    homeAddress = '广州越秀路6号'; phone = '13800008888'; email = 'doctor@adc.example'
    qualifications = @(@{qualificationId = $qual.id; verifiedAt = $null})
}
$dentist = Invoke-Adc POST '/dentists' $hq $dBody -Expect 201
(Invoke-Adc POST '/dentists' $hq $dBody -Expect 409).code
$dPath = "/dentists/$($dentist.id)"
Invoke-Adc GET '/dentists' $hq
$dBody.active = $true
$dBody.version = $dentist.version
$dBody.qualifications[0].verifiedAt = '2026-01-05T10:00:00'
Invoke-Adc PUT $dPath $hq $dBody
Invoke-Adc GET $dPath $hq | ConvertTo-Json -Depth 6
```

## 七、治疗项目与价格

为项目登记首次价格，更新名称，再添加未来的价格。同项目同一生效日期再次调价应返回 CONFLICT。GET 结果中的 prices 按生效日期递增，今天的 currentPrice 应为 80。

```powershell
$itemBody = @{
    name = "联调项目-$tag"; standardUnit = '次'; quantityScale = 0
    firstPrice = @{effectiveFrom = '2020-01-01'; unitPrice = 80.00}
}
$item = Invoke-Adc POST '/treatment-items' $hq $itemBody -Expect 201
$itemPath = "/treatment-items/$($item.id)"
Invoke-Adc GET '/treatment-items' $hq
Invoke-Adc PUT $itemPath $hq @{
    name = "联调项目已修改-$tag"; standardUnit = '次'; quantityScale = 0
    active = $true; version = $item.version
}
$priceBody = @{effectiveFrom = '2099-01-01'; unitPrice = 90.00}
Invoke-Adc POST "$itemPath/prices" $hq $priceBody
(Invoke-Adc POST "$itemPath/prices" $hq $priceBody -Expect 409).code
Invoke-Adc GET $itemPath $hq | ConvertTo-Json -Depth 6
```

## 八、患者、疑似重复和岗位权限

前台先建一个患者，再尝试登记一名同名、同出生日期的患者。第二次新建返回 409，current 是候选摘要数组。示例将两条记录作为已核对的不同演示患者，确认后应得到不同的 P 加六位数字账号。

```powershell
$pBody = @{
    name = "联调患者-$tag"; birthDate = '1990-05-01'; billingAddress = '广州越秀路18号'
    phone = '13900008888'; email = $null; emergencyName = '黄敏'; emergencyPhone = '13900008889'
    allergyIds = @($allergies[0].id); confirmNotDuplicate = $false
}
$patient = Invoke-Adc POST '/patients' $front $pBody -Expect 201
$pBody.phone = '13900007777'
$candidates = Invoke-Adc POST '/patients' $front $pBody -Expect 409
$candidates | ConvertTo-Json -Depth 6
$pBody.confirmNotDuplicate = $true
$second = Invoke-Adc POST '/patients' $front $pBody -Expect 201
$patient.accountNo
$second.accountNo

$pPath = "/patients/$($second.id)"
$pBody.version = $second.version
$pBody.billingAddress = '广州天河路22号'
$pBody.allergyIds = @()
Invoke-Adc PUT $pPath $front $pBody
Invoke-Adc GET $pPath $doctor | ConvertTo-Json -Depth 6
$kw = [uri]::EscapeDataString($pBody.name)
Invoke-Adc GET "/patients?keyword=$kw&page=0&size=20" $front | ConvertTo-Json -Depth 6
(Invoke-Adc PUT $pPath $doctor $pBody -Expect 403).code
(Invoke-Adc GET $pPath $hq -Expect 403).code
$adcHttp.Dispose()
```

列表应返回两条候选患者，页码从 0 开始。第二名患者的详情中 allergies 为空数组，allergyVerifiedAt 为 null。牙医修改患者、总部读取患者详情均返回 FORBIDDEN。

## 十、约定口径与演示差异

1. 依第 9.5 节，患者疑似重复的 `409 CONFLICT` 携带候选摘要数组；其余唯一冲突的 `current` 为 `null`。四类档案的 `409 CHANGED` 均携带与详情 GET 一致的完整对象。
2. 登录、退出以及第 6.3 节列出的只计算接口采用约定中的去重豁免。新增调价按第 9.4 节接收日期与金额，并将项目版本加一。
3. V5 按员工编号关联 D001、D002，只补资质。两人的出生日期和家庭地址沿用 V3，其他新增基础资料取自前端种子。
