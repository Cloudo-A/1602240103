# 取消统计、治疗需求与季度核算联调

第 4 轮的 7 个接口均由总部账号 `hq1` 调用，对应协作约定第 9.10—9.12 节。下面按演示顺序给出请求和预期结果。查询、预览及预期失败的请求可以反复运行。**成功确认会替换演示库中的季度核算结果，成功开单会为指定就诊留下结算单。** 如需保留“第三季度有一条待开单就诊”的演示现场，可执行到第三季度的首次预览和确认受阻为止。

## 初始化手动联调窗口

以下代码块依次粘贴到同一个 PowerShell 窗口。请求函数显示实际状态码并检查预期值，失败响应也可以直接查看 `code`、`fieldErrors` 和 `current`。预览免传请求标识。季度确认和前台开单会自动使用新的 `X-Request-Id`，也可以显式指定标识来重放同一次请求。

```powershell
Add-Type -AssemblyName System.Net.Http
$quarterHttp = [System.Net.Http.HttpClient]::new()
$quarterBase = 'http://localhost:8080/api'
function Invoke-QuarterApi {
    param([string]$Method, [string]$Path, [string]$Token, $Body = $null,
          [int]$Expect = 200, [string]$RequestId)
    $request = [System.Net.Http.HttpRequestMessage]::new(
        [System.Net.Http.HttpMethod]::new($Method), "$quarterBase$Path")
    try {
        if ($Token) { $request.Headers.Add('Authorization', "Bearer $Token") }
        if ($Method -eq 'POST' -and $Path -match '/(confirm|settlement)$') {
            if (!$RequestId) { $RequestId = [guid]::NewGuid().ToString() }
            $request.Headers.Add('X-Request-Id', $RequestId)
        }
        if ($null -ne $Body) {
            $jsonText = ConvertTo-Json -InputObject $Body -Compress -Depth 15
            $request.Content = [System.Net.Http.StringContent]::new(
                $jsonText, [Text.Encoding]::UTF8, 'application/json')
        }
        $response = $quarterHttp.SendAsync($request).GetAwaiter().GetResult()
        try {
            $status = [int]$response.StatusCode
            $raw = $response.Content.ReadAsStringAsync().GetAwaiter().GetResult()
            Write-Host "$Method $Path -> $status"
            if ($status -ne $Expect) { throw "预期 $Expect，实际 $status，响应 $raw" }
            if ($raw) { ConvertFrom-Json -InputObject $raw }
        } finally { $response.Dispose() }
    } finally { $request.Dispose() }
}
function Get-QuarterToken([string]$Name) {
    (Invoke-QuarterApi POST '/auth/login' -Body @{username=$Name; password='123456'}).token
}
function Get-CostRows($Preparation) {
    foreach ($row in $Preparation.rows) {
        $supply = $row.supplyCost
        $operating = $row.operatingCost
        $basis = $row.basis
        if ($null -eq $supply) { $supply = 0 }
        if ($null -eq $operating) { $operating = 0 }
        if ([string]::IsNullOrWhiteSpace($basis)) { $basis = '演示按本季度费用登记核对' }
        @{dentistId=$row.dentistId; supplyCost=$supply; operatingCost=$operating; basis=$basis}
    }
}
$hq = Get-QuarterToken 'hq1'
$front = Get-QuarterToken 'front1'
$doctor = Get-QuarterToken 'dentist1'
```

## 总部查询取消统计、预约明细和治疗需求

以下三个 GET 均应返回 200。原始 V7 数据中，2026 年 10 月福田诊所只有 10 月 20 日的一次预约，已取消，所以 `total=1`、`cancelled=1`、`pendingVerify=0`、`rate=1.0000`。把查询范围缩到 10 月 8 日，未发生预约的诊所仍在结果里，`rate` 为 `null`。明细包含这家诊所在所选期间的全部预约，按预约时间升序。

```powershell
$period = 'from=2026-10-01&to=2026-10-31'
$summary = Invoke-QuarterApi GET "/stats/cancellations?$period" $hq
$summary | Select-Object from,to,periodEnded,generatedAt
$summary.rows | Format-Table clinicId,clinicName,total,cancelled,pendingVerify,rate
$clinic = $summary.rows | Where-Object { $_.clinicName -eq '福田诊所' } | Select-Object -First 1
if (!$clinic) { $clinic = $summary.rows | Select-Object -First 1 }
$details = @(Invoke-QuarterApi GET "/stats/cancellations/details?clinicId=$($clinic.clinicId)&$period" $hq)
$details | Format-Table id,scheduledAt,status
$oneDay = Invoke-QuarterApi GET '/stats/cancellations?from=2026-10-08&to=2026-10-08' $hq
$oneDay.rows | Where-Object { $_.total -eq 0 } | ConvertTo-Json -Depth 4
$demand = Invoke-QuarterApi GET "/stats/demand-qualification?clinicIds=$($clinic.clinicId)&$period" $hq
$demand.demand | Format-Table clinicName,itemName,unitName,intendedCount,actualQuantity
$demand.qualifications | Format-Table name,verifiedCount
$demand.incomplete | Format-Table employeeNo,name,issue
```

福田诊所 10 月唯一的预约已取消，原始样例的 `demand` 是空数组。去掉诊所筛选后可看到越秀诊所“局部麻醉”的实际用量 1.5 毫升，意向次数为 0。即使加上 `clinicIds`，资质仍覆盖全部启用牙医，D003 的口腔正畸列为待核实。

```powershell
$allDemand = Invoke-QuarterApi GET "/stats/demand-qualification?$period" $hq
$allDemand.demand | Format-Table clinicName,itemName,unitName,intendedCount,actualQuantity
(Invoke-QuarterApi GET '/stats/cancellations?from=2026-10-31&to=2026-10-01' $hq -Expect 400).code
(Invoke-QuarterApi GET "/stats/cancellations?$period" $front -Expect 403).code
(Invoke-QuarterApi GET "/stats/demand-qualification?$period" $doctor -Expect 403).code
(Invoke-QuarterApi GET '/quarters' $front -Expect 403).code
```

## 读取第二季度并演示重新确认

已确认列表和季度准备数据均返回 200。原始 V10 样例中，2026 年第二季度的四位牙医收入均为 0，运营费用合计 5,500.00 元，公司净利润为 −5,500.00 元。`fundStatus` 为 `TRANSFERRED`，`incentiveFund` 为 `null`。`firstConfirmedAt` 为 `2026-07-08T16:00:00`，从 7 月 1 日至 7 月 8 日共 6 个工作日。

```powershell
$quarters = @(Invoke-QuarterApi GET '/quarters' $hq)
$quarters | Format-Table year,quarter,companyNetProfit,fundStatus,firstConfirmedAt,collectionWorkdays
$q2 = Invoke-QuarterApi GET '/quarters/2026/2' $hq
$q2.rows | Format-Table employeeNo,name,revenue,supplyCost,operatingCost,basis
$q2.existing | Select-Object firstConfirmedAt,confirmedAt,collectionWorkdays,companyNetProfit,fundNote
$rows2 = @(Get-CostRows $q2)
$preview2 = Invoke-QuarterApi POST '/quarters/2026/2/preview' $hq @{rows=$rows2}
$preview2 | Select-Object companyNetProfit,incentiveFund,fundNoteRequired,problems,checkToken
if (!$preview2.checkToken) { throw "请先核对二季度数据：$($preview2.problems -join '；')" }
$badNote = Invoke-QuarterApi POST '/quarters/2026/2/confirm' $hq @{rows=$rows2; checkToken=$preview2.checkToken} -Expect 400
$badNote.fieldErrors | Format-Table field,message
$badToken = Invoke-QuarterApi POST '/quarters/2026/2/confirm' $hq @{
    rows=$rows2; fundNote='二季度基金由总部处理'; checkToken='invalid-demo-token'
} -Expect 409
$badToken | Select-Object code,current
```

预览应返回 200，`fundNoteRequired=true`。两次失败确认分别显示 `INVALID_INPUT`（字段 `fundNote`）和 `CHANGED`（`current=null`）。继续执行下一段会用新请求标识重新确认二季度，并以同一标识、同一内容重试。两次响应均为 200，重试应返回首次响应中的 `confirmedAt`，`firstConfirmedAt` 和汇总周期应与原记录一致。

```powershell
$confirm2 = @{rows=$rows2; fundNote=$q2.existing.fundNote; checkToken=$preview2.checkToken}
$q2Id = [guid]::NewGuid().ToString()
$saved2 = Invoke-QuarterApi POST '/quarters/2026/2/confirm' $hq $confirm2 -RequestId $q2Id
$retry2 = Invoke-QuarterApi POST '/quarters/2026/2/confirm' $hq $confirm2 -RequestId $q2Id
$saved2 | Select-Object confirmedAt,firstConfirmedAt,collectionWorkdays,fundStatus,fundTransferAt
if ($saved2.firstConfirmedAt -ne $q2.existing.firstConfirmedAt -or
    $saved2.collectionWorkdays -ne $q2.existing.collectionWorkdays -or
    $saved2.confirmedAt -ne $retry2.confirmedAt) { throw '首次确认时间、汇总周期或重放结果不符' }
```

## 第三季度先开单，再核算

V7 中，患者账号 `P000008` 的张伟于 2026 年 9 月 29 日 10:35 到诊，诊疗已确认、结算单尚未开具。准备数据会在 `unsettledVisits` 中列出该就诊。即使成本和依据齐全，预览仍返回 200，并列出未开单问题，`checkToken=null`。此时确认返回 409 `STATE_NOT_ALLOWED`。如果此前已经给这次就诊开过单，脚本将跳过这项阻断测试。

```powershell
$q3 = Invoke-QuarterApi GET '/quarters/2026/3' $hq
$rows3 = @(Get-CostRows $q3)
$q3.unsettledVisits | Format-Table id,arrivedAt,status,total
$first3 = Invoke-QuarterApi POST '/quarters/2026/3/preview' $hq @{rows=$rows3}
$first3 | Select-Object companyNetProfit,problems,checkToken
if (@($q3.unsettledVisits).Count -gt 0) {
    if ($first3.checkToken) { throw '有待开单就诊时预览令牌应为 null' }
    $unsettledCount = @($q3.unsettledVisits).Count
    if (!($first3.problems -like "本季度还有 $unsettledCount 次已确认但未开结算单的就诊*")) {
        throw '预览缺少含未开单次数的提示'
    }
    $blocked = Invoke-QuarterApi POST '/quarters/2026/3/confirm' $hq @{
        rows=$rows3; fundNote=$null; checkToken=$first3.checkToken
    } -Expect 409
    $blocked | Select-Object code,message
}
```

下面只为上述 V7 演示就诊开单，使用前台账号 `front1` 先预览（200）再开具（201）。原始价格为根管治疗 600.00 元、局部麻醉 35.00 元，合计 635.00 元。这笔收入按 9 月 29 日的实际到诊日期计入三季度。

```powershell
$target = $q3.unsettledVisits | Where-Object {
    $_.patient.accountNo -eq 'P000008' -and ([datetime]$_.arrivedAt).ToString('yyyy-MM-dd HH:mm') -eq '2026-09-29 10:35'
} | Select-Object -First 1
if ($target) {
    $settlePath = "/visits/$($target.id)"
    $billPreview = Invoke-QuarterApi POST "$settlePath/settlement-preview" $front
    if (!$billPreview.existing) {
        $bill = Invoke-QuarterApi POST "$settlePath/settlement" $front @{checkToken=$billPreview.checkToken} -Expect 201
        $bill | Select-Object settlementNo,visitId,total,issuedAt
    }
}
$q3 = Invoke-QuarterApi GET '/quarters/2026/3' $hq
$rows3 = @(Get-CostRows $q3)
$ready3 = Invoke-QuarterApi POST '/quarters/2026/3/preview' $hq @{rows=$rows3}
if ($ready3.checkToken) {
    $note3 = $null
    if ($ready3.fundNoteRequired) { $note3 = '本季度基金由总部处理' }
    $saved3 = Invoke-QuarterApi POST '/quarters/2026/3/confirm' $hq @{
        rows=$rows3; fundNote=$note3; checkToken=$ready3.checkToken
    }
    $saved3 | Select-Object year,quarter,companyNetProfit,incentiveFund,fundStatus,firstConfirmedAt
} else {
    $ready3.problems
}
```

前台开单后须用总部账号重新获取准备数据和预览令牌。示例中首次填报的费用按 0 演示；正式核算应填写实际成本、费用和核对依据。成功确认返回 200，再次查询 `GET /api/quarters` 即可看到第三季度。若库中另有未开单就诊，上述脚本会显示阻断原因，保留那些就诊的原状态。

## 季度未结束与非法季度

用北京时间计算当前季度，准备数据应有 `quarterEnded=false`。预览为 200，`problems` 至少包含“季度未结束”，如还有未开单就诊会一并列出，`checkToken` 为 `null`。确认应返回 409 `STATE_NOT_ALLOWED`。季度编号 5 应返回 400 `INVALID_INPUT`。

```powershell
$today = [DateTimeOffset]::UtcNow.ToOffset([TimeSpan]::FromHours(8))
$currentQ = [int]([Math]::Ceiling($today.Month / 3.0))
$currentPath = "/quarters/$($today.Year)/$currentQ"
$current = Invoke-QuarterApi GET $currentPath $hq
$currentRows = @(Get-CostRows $current)
$pending = Invoke-QuarterApi POST "$currentPath/preview" $hq @{rows=$currentRows}
$pending | Select-Object problems,checkToken
if ($pending.checkToken -or !($pending.problems -like '季度还没有结束*')) {
    throw '未结束的季度应提示原因，且预览令牌应为 null'
}
if (@($current.unsettledVisits).Count -gt 0) {
    $unsettledCount = @($current.unsettledVisits).Count
    if (!($pending.problems -like "本季度还有 $unsettledCount 次已确认但未开结算单的就诊*")) {
        throw '预览应同时提示季度未结束和未开单就诊'
    }
}
(Invoke-QuarterApi POST "$currentPath/confirm" $hq @{rows=$currentRows; checkToken=$pending.checkToken} -Expect 409).code
(Invoke-QuarterApi GET '/quarters/2026/5' $hq -Expect 400).code
$quarterHttp.Dispose()
```

## 联调口径

- 预览同时展示内容问题与业务状态问题。只要存在任一问题，`checkToken` 为 `null`，页面据此禁用确认。
- 缺少牙医的字段为 `rows`，多出或重复牙医的字段为 `rows[i].dentistId`。金额和依据问题定位到请求中对应行。
- 超出数据库金额范围的输入会列为预览问题，确认时返回 400。演示脚本在已有第二季度确认结果时保留现有数据。

## 验证结果

已在独立 MySQL 8.0.46 上验证空库执行 V1—V10，以及已有 V8 的库接续 V9、V10。旧季度记录的首次确认时间从原确认时间正确回填。两种环境的 `mvnw.cmd test` 均为 40 项通过。文档中的 HTTP 命令也已在独立实例逐条执行，包括第 3 季度先被未开单就诊阻断、前台开单后重新预览并完成核算。
