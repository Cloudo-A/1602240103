# 账号与操作记录联调

本页对应协作约定 v1.7 第 9.13、9.14 节。手动流程创建一个随机命名的临时前台账号，用它验证改名、重置密码、自助改密和停用。临时账号最终处于停用状态，操作记录会保留。

## 一、启动演示后端

准备 Java 17、MySQL 8，并确认 backend/application-local.properties 连接本机演示库。在第一个 PowerShell 窗口运行以下命令。Flyway 会接续 V10，执行 V11 为 app_user 增加版本号，已有账号初始版本为 0。本轮沿用原有演示账号。

```powershell
Set-Location 'E:\adc-system\backend'
$env:SPRING_PROFILES_ACTIVE = 'demo'
.\mvnw.cmd spring-boot:run
```

在测试用 MySQL 实例中建库，给测试账号授予该库的迁移、建表及读写权限。

## 三、准备 HTTP 请求函数

下面各节在同一个 PowerShell 窗口依次执行。函数只打印方法、路径和状态码。预期的错误响应可读取 message、fieldErrors、current。示例中的密码均为演示用临时值。

```powershell
Add-Type -AssemblyName System.Net.Http
$adcBase = 'http://localhost:8080/api'
$accountHttp = [System.Net.Http.HttpClient]::new()
function Invoke-AdcAccount {
    param([string]$Method,[string]$Path,[string]$Token,$Body=$null,
          [int]$Expect=200,[string]$RequestId)
    $request = [System.Net.Http.HttpRequestMessage]::new(
        [System.Net.Http.HttpMethod]::new($Method), "$adcBase$Path")
    try {
        if ($Token) { $request.Headers.Add('Authorization',"Bearer $Token") }
        if ($Method -in 'POST','PUT' -and $Path -ne '/auth/login') {
            if (!$RequestId) { $RequestId = [guid]::NewGuid().ToString() }
            $request.Headers.Add('X-Request-Id',$RequestId)
        }
        if ($null -ne $Body) {
            $jsonBody = ConvertTo-Json -InputObject $Body -Depth 10 -Compress
            $request.Content = [System.Net.Http.StringContent]::new(
                $jsonBody,[Text.Encoding]::UTF8,'application/json')
        }
        $response = $accountHttp.SendAsync($request).GetAwaiter().GetResult()
        try {
            $code = [int]$response.StatusCode
            $raw = $response.Content.ReadAsStringAsync().GetAwaiter().GetResult()
            Write-Host "$Method $Path -> $code"
            if ($code -ne $Expect) { throw "预期 $Expect，实际 $code。请检查步骤及服务端日志。" }
            if ($raw) { ConvertFrom-Json -InputObject $raw }
        } finally { $response.Dispose() }
    } finally { $request.Dispose() }
}
function Get-AdcAccountToken([string]$User,[string]$Secret) {
    (Invoke-AdcAccount POST '/auth/login' -Body @{username=$User; password=$Secret}).token
}
$hq = Get-AdcAccountToken 'hq1' '123456'
$doctor = Get-AdcAccountToken 'dentist1' '123456'
$hqId = (Invoke-AdcAccount GET '/auth/me' $hq).id
$doctorId = (Invoke-AdcAccount GET '/auth/me' $doctor).dentistId
$tag = [guid]::NewGuid().ToString('N').Substring(0,10)
$loginName = "test_front_$tag"
$initialSecret = 'DemoOnly_First1'
$changedSecret = "DemoOnly_Changed_$tag"
$boundarySecret = '测' * 24
$tooManyBytes = $boundarySecret + 'a'
```

## 四、新建和修改临时账号

登录名限 3 至 40 位字母、数字、下划线。密码限 6 至 64 个字符，同时最多 72 个 UTF-8 字节。24 个“测”恰好 72 字节，再加一个 ASCII 字符为 73 字节。超过字节上限的字段提示为“密码太长（最多 72 个字节，约 24 个汉字）”。下面先检查错误输入，再创建临时前台账号并修改显示姓名。

```powershell
$create = @{username=$loginName; displayName="联调前台$tag"; role='FRONT_DESK'; dentistId=$null; password=$initialSecret}
foreach ($invalidSecret in @('12345',('a' * 65),$tooManyBytes)) {
    $invalid = $create.Clone()
    $invalid.password = $invalidSecret
    $errorBody = Invoke-AdcAccount POST '/users' $hq $invalid -Expect 400
    $errorBody.fieldErrors | Select-Object field,message
}
$wrongBinding = $create.Clone()
$wrongBinding.dentistId = $doctorId
(Invoke-AdcAccount POST '/users' $hq $wrongBinding -Expect 400).fieldErrors
$wrongBinding.role = 'DENTIST'
(Invoke-AdcAccount POST '/users' $hq $wrongBinding -Expect 409).code
$created = Invoke-AdcAccount POST '/users' $hq $create -Expect 201
$userPath = "/users/$($created.id)"
$created | Select-Object id,username,displayName,role,dentist,active,version
(Invoke-AdcAccount POST '/users' $hq $create -Expect 409).code
$edit = @{displayName="联调前台已改名$tag"; dentistId=$null; active=$true; version=$created.version}
$edited = Invoke-AdcAccount PUT $userPath $hq $edit
$edited | Select-Object id,displayName,version
$stale = Invoke-AdcAccount PUT $userPath $hq $edit -Expect 409
$stale | Select-Object code,current
Invoke-AdcAccount GET '/users' $hq | Where-Object { $_.id -eq $created.id }
```

## 五、重置密码并验证旧令牌作废

总部将临时账号密码重置为上述 72 字节边界值。两个独立会话的旧令牌均应返回 401，原密码登录时应提示“用户名或密码错误”。临时前台和演示牙医访问账号管理、操作记录应返回 403。

```powershell
$oldWeb = Get-AdcAccountToken $loginName $initialSecret
$oldMobile = Get-AdcAccountToken $loginName $initialSecret
foreach ($restricted in @($oldWeb,$doctor)) {
    (Invoke-AdcAccount GET '/users' $restricted -Expect 403).code
    (Invoke-AdcAccount GET '/operation-logs' $restricted -Expect 403).code
}
(Invoke-AdcAccount POST "$userPath/reset-password" $hq @{newPassword=$tooManyBytes} -Expect 400).fieldErrors
$reset = Invoke-AdcAccount POST "$userPath/reset-password" $hq @{newPassword=$boundarySecret}
$reset | Select-Object id,active,version
(Invoke-AdcAccount GET '/auth/me' $oldWeb -Expect 401).code
(Invoke-AdcAccount GET '/auth/me' $oldMobile -Expect 401).code
(Invoke-AdcAccount POST '/auth/login' -Body @{username=$loginName; password=$initialSecret} -Expect 401).message
$currentToken = Get-AdcAccountToken $loginName $boundarySecret
$otherToken = Get-AdcAccountToken $loginName $boundarySecret
```

## 六、自助改密、重放和停用

原密码错误时 fieldErrors 指向 oldPassword，新旧密码相同时指向 newPassword。使用同一个 X-Request-Id 重试改密，返回第一次的结果。当前令牌继续有效，其他令牌作废。随后使用最新版本停用临时账号，验证全部令牌失效及停用后的登录提示。

```powershell
(Invoke-AdcAccount POST '/auth/change-password' $currentToken @{oldPassword='wrong-demo'; newPassword=$changedSecret} -Expect 400).fieldErrors
(Invoke-AdcAccount POST '/auth/change-password' $currentToken @{oldPassword=$boundarySecret; newPassword=$boundarySecret} -Expect 400).fieldErrors
$change = @{oldPassword=$boundarySecret; newPassword=$changedSecret}
$changeId = [guid]::NewGuid().ToString()
$changed = Invoke-AdcAccount POST '/auth/change-password' $currentToken $change -RequestId $changeId
$replay = Invoke-AdcAccount POST '/auth/change-password' $currentToken $change -RequestId $changeId
if (!$changed.ok -or !$replay.ok) { throw '改密或重放响应异常' }
(Invoke-AdcAccount GET '/auth/me' $currentToken).username
(Invoke-AdcAccount GET '/auth/me' $otherToken -Expect 401).code
$newSession = Get-AdcAccountToken $loginName $changedSecret
$latest = Invoke-AdcAccount GET '/users' $hq | Where-Object { $_.id -eq $created.id }
$disabled = Invoke-AdcAccount PUT $userPath $hq @{
    displayName=$latest.displayName; dentistId=$null; active=$false; version=$latest.version
}
$disabled | Select-Object id,active,version
(Invoke-AdcAccount GET '/auth/me' $currentToken -Expect 401).code
(Invoke-AdcAccount GET '/auth/me' $newSession -Expect 401).code
$denied = Invoke-AdcAccount POST '/auth/login' -Body @{username=$loginName; password=$changedSecret} -Expect 401
if ($denied.message -ne '账号已停用，请联系总部') { throw '停用账号登录消息不符合约定' }
$denied.message
```

## 七、按操作人、动作、对象和期间查日志

改密操作人是临时前台，重置操作人是总部，两条记录的对象都是临时账号。keyword 可匹配操作人的登录名、当前显示姓名或对象 ID。操作时间按北京时间从近到远排列。页码从 0 开始，size 默认 20、最大 100，省略起止日期时默认最近七天。

```powershell
$bjToday = [DateTimeOffset]::UtcNow.ToOffset([TimeSpan]::FromHours(8))
$from = $bjToday.AddDays(-1).ToString('yyyy-MM-dd')
$to = $bjToday.ToString('yyyy-MM-dd')
$range = "from=$from&to=$to"
$byActor = Invoke-AdcAccount GET "/operation-logs?${range}&userId=$($created.id)&action=CHANGE_PASSWORD&targetType=user&keyword=$loginName&page=0&size=1" $hq
if ($byActor.total -ne 1 -or $byActor.items[0].targetType -ne 'USER' -or $byActor.items[0].targetId -ne $created.id) {
    throw '改密重放条数或日志对象异常'
}
$byActor.items | Select-Object occurredAt,username,displayName,action,targetType,targetId
$next = Invoke-AdcAccount GET "/operation-logs?${range}&userId=$($created.id)&action=CHANGE_PASSWORD&page=1&size=1" $hq
if ($next.total -ne 1 -or $next.items.Count -ne 0) { throw '翻页总数或返回条数异常' }
$byAdmin = Invoke-AdcAccount GET "/operation-logs?${range}&userId=$hqId&action=RESET_PASSWORD&targetType=USER&keyword=$($created.id)&page=0&size=100" $hq
$resetEntry = $byAdmin.items | Where-Object { $_.targetId -eq $created.id } | Select-Object -First 1
if (!$resetEntry -or $null -eq $resetEntry.detail -or $resetEntry.detail -is [string]) { throw '缺少重置密码操作详情' }
$resetEntry | Select-Object occurredAt,username,displayName,action,targetType,targetId
$resetEntry.detail | Select-Object id,username,displayName,role,active,version
$recent = Invoke-AdcAccount GET '/operation-logs' $hq
$recent | Select-Object total
(Invoke-AdcAccount GET "/operation-logs?from=$to&to=$from" $hq -Expect 400).fieldErrors
$accountHttp.Dispose()
```

targetType 在响应中统一为大写，筛选也涵盖旧的大小写混用记录。detail 中合法的 JSON 解析后返回，旧记录中无法解析的文本按原文返回。账号操作详情只记录非敏感资料。

## 九、约定口径

停用账号登录文案按已确认的第 9.13 节返回“账号已停用，请联系总部”。协作约定第 4 节表格仍写“账号已停用”。新建、重置和自助改密都按第 9.13 节校验字符数与 UTF-8 字节数，并直接使用 BCrypt。

## 十、验证结果

在独立 MySQL 8.0.46 上验证了空库 V1—V11 及已有 V10 接续 V11，两个环境中的 47 项 Maven 测试均通过。四个既有演示账号的初始版本均为 0。文档第三至第七节的 PowerShell 请求也已逐条实测，覆盖新接口、令牌作废、改密重放和日志查询。
