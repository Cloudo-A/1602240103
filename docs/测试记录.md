## 七、如何复现自动测试

需要 JDK 17 和 MySQL 8。先在 MySQL 中新建一个**专用的空数据库** `adc_auth_test`（测试会在其中建表并写入数据，不要使用正式库），测试通过以下环境变量连接：

```
ADC_TEST_DB_HOST=127.0.0.1
ADC_TEST_DB_PORT=3306
ADC_TEST_DB_USER=root
ADC_TEST_DB_PASSWORD=
```

然后在 `backend` 目录执行：

```
.\mvnw.cmd test
```

结果汇总在控制台的 `Tests run` 一行，逐项报告在 `backend/target/surefire-reports/`。
